# دليل الإصدار 0.3 — الحسابات وإعادة الضبط

## أول دخول بعد التحديث

اسم الدخول للحساب القديم هو `admin`، وكلمة المرور هي نفس كلمة المرور السابقة. لا توجد كلمة مرور عامة أو افتراضية جديدة. من «إدارة النظام» يستطيع الأدمن إضافة حسابات بأسماء دخول مستقلة، تحديد أدمن أو حساب عادي، إيقاف حساب أو تغيير كلمة مروره. لا يمكن تعطيل حساب الأدمن الحالي أو سحب صلاحياته من نفسه.

كل مستخدم يستطيع تغيير كلمة مروره من الإعدادات بعد إدخال الكلمة الحالية. القفل أو تسجيل الدخول بحساب آخر يغيّر الصلاحيات المعروضة، والتحقق الحقيقي من الصلاحيات يتم داخل التطبيق عند كل طلب.

## الصلاحيات

| العملية | حساب عادي | أدمن |
|---|---|---|
| الموظفون والإضافة والتعديل والإيقاف والحذف مع حفظ التاريخ | نعم | نعم |
| المتابعة اليومية والرواتب المسودة والتصدير وتسجيل صرف المعتمد | نعم | نعم |
| إنشاء نسخة احتياطية | نعم | نعم |
| تغيير كلمة مروره | نعم | نعم |
| اعتماد الشهر | لا | نعم |
| تعديل المعادلات وإعدادات الشركة | لا | نعم |
| استعادة نسخة أو إعادة الضبط | لا | نعم |
| إدارة الحسابات والصلاحيات | لا | نعم |

## إعادة ضبط شهر

من إدارة النظام اختر الشهر ثم «معاينة إعادة ضبط الشهر». تظهر أعداد الكشوف والرواتب والحركات المتأثرة. اكتب `RESET YYYY-MM` للشهر المعروض وأدخل كلمة مرور الأدمن الحالي.

يمسح البرنامج الحركات اليومية وتاريخ المتغيرات لهذا الشهر فقط، ويعيد الحوافز والإعاشة والمواصلات وأخرى والتكليف والسلف والغياب والتأخير والجزاءات والقيم المخصصة اليدوية إلى الصفر. يمسح الأساسي الشهري داخل الكشف أيضًا، ويصبح الراتب غير مكتمل حتى إدخال الأساسي مجددًا. يحتفظ ببيانات الموظفين وبالأساسي المرجعي داخل ملف كل موظف دون تغيير. الشهر المعتمد يعود لمسودة، وتلغى علامات المراجعة والصرف. لا يتغير أي شهر آخر.

بعد إعادة الضبط لا تحسب أي بنود تلقائية حتى إعادة إدخال الأساسي. القواعد الآلية مثل صندوق الزمالة والحقول المخصصة الثابتة أو المحسوبة تظل تُطبق حسب الإعدادات؛ إعادة ضبط المدخلات لا تحذف معادلات الشركة. إذا لم يكن للشهر كشف أو حركات، فلا ينشئ الإجراء كشفًا جديدًا.

## إعادة ضبط النظام

تعرض المعاينة إجماليات كل النظام، وتتطلب `RESET ALL` وكلمة مرور الأدمن. تمسح جميع الشهور والرواتب والحركات وتاريخ المدخلات، وسجل العمليات السابق والاستيراد وإصدارات السياسات. تعود إعدادات الشركة والمعادلات إلى الافتراضيات.

تبقى ملفات الموظفين الحاليين والمتوقفين كما هي، بما فيها الأساسي وبيانات الدفع، وتبقى حسابات الدخول. الموظفون المحذوفون سابقًا تزال سجلاتهم الداخلية عند مسح معاملاتهم كلها. النسخ الاحتياطية القديمة لا تُحذف. ينشأ سجل جديد يوثق عملية إعادة الضبط ومن نفذها ومكان النسخة السابقة.

## النسخة الاحتياطية والتأكيد

يحفظ البرنامج نسخة تلقائية قبل أي إعادة ضبط. إذا فشل النسخ لا يبدأ المسح. إذا تغيرت البيانات بعد فتح المعاينة، تُرفض العملية حتى تعيد فتح المعاينة. أثناء التنفيذ يمنع التعديل المتزامن. يظهر مسار النسخة بعد النجاح؛ يستطيع الأدمن استعادتها من الإعدادات. هذه آلية داخل البرنامج؛ لم تُنفذ إعادة ضبط على بياناتك الحقيقية أثناء التطوير.

## حذف الموظف أم إيقافه؟

- **الحذف مع حفظ التاريخ:** يختفي من قائمة الموظفين والمتابعة اليومية والكشوف الجديدة. تبقى جميع كشوفه وحركاته القديمة باسمه وبياناته المحفوظة، بما فيها المسودات الموجودة. لا يعاد استخدام هويته أو كوده تلقائيًا. يمكن لأي حساب عادي تنفيذ الحذف بعد تأكيده.
- **الإيقاف:** يبقى ملف الموظف ظاهرًا كمتوقف ويمكن إعادة تنشيطه. لا يدخل الكشوف الجديدة إلا وفق أهلية فترة عمله؛ تاريخ انتهاء العمل يسمح بإدراجه في الشهور التاريخية المستحقة. معاملاته الموجودة لا تمسح.

المخطط أصبح الإصدار 3 لمنع نسخة التطبيق الأقدم من فتح البيانات المرقاة دون فهم الصلاحيات والحذف. توجد نسخة قبل الترقية. استخدم المثبت 0.3.0 أو أحدث.


## السوبر أدمن ورؤية الحسابات
- المستوى `super_admin` يملك جميع صلاحيات الأدمن، ويستطيع تعيين المستويات وتغيير `is_hidden`.
- الأدمن يحتفظ بإدارة الحسابات الظاهرة العادية وحسابات الأدمن، ولا يستطيع تعديل حساب سوبر أدمن أو تغيير الرؤية أو رفع الصلاحية إلى سوبر أدمن.
- الحساب المخفي لا يظهر في قائمة الحسابات لغير السوبر أدمن، ولا يمكن للأدمن تعديله بطلب مباشر. يظل تسجيل دخوله متاحًا إذا كان نشطًا.
- تُحجب سجلات إدارة الحساب المخفي والسجلات المرتبطة به من استجابات السجل لغير السوبر أدمن. الإخفاء داخل التطبيق؛ ملفات قاعدة البيانات والنسخ الاحتياطية الكاملة تظل تحتوي الحسابات.
- القيمة الافتراضية لـ `is_hidden` هي `false`. الحسابات الحالية لا تُرفع صلاحياتها تلقائيًا. عند إنشاء مساحة عمل جديدة يكون حساب التهيئة الأول سوبر أدمن.
- لا يمكن تعطيل الحساب الحالي أو خفض مستواه، ويجب الاحتفاظ بسوبر أدمن نشط عند وجود هذا المستوى.
