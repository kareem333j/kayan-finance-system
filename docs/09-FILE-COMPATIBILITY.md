# توافق الملفات — الإصدار 0.4.2

ملفات بيانات الموظفين المصدّرة من البرنامج يمكن استيرادها مرة أخرى. يتم التعرف على عناوين الأعمدة العربية والإنجليزية المعروفة دون اشتراط ترتيبها، سواء كانت من قالب العمال القديم أو تصدير بيانات الموظفين السابق. التصدير الجديد يحتفظ بالكود والاسم والحالة دائمًا، ويحترم اختيار بقية الحقول وإخفاء الراتب.

الاستيراد يحافظ على الحقول المعروفة والأرقام النصية التي تبدأ بصفر. الملف لا يضيف نسخة ثانية من الموظف إذا كانت بياناته نفسها مسجلة. إذا اختلفت البيانات مع نفس الكود، يظهر الصف كتحديث يحتاج اختيار المستخدم؛ الحقول التي لم تُصدّر لا تمسح القيم الموجودة. التغييرات التي تحدث بعد المعاينة تمنع تطبيق تحديث قديم. الصفوف ذات التاريخ أو الحالة غير الصحيحة تبقى ظاهرة للمراجعة ولا تستورد تلقائيًا.

استعادة النسخ تعمل مع إصدارات قاعدة البيانات 1 و2 و3 المستخدمة حتى الإصدار الحالي، سواء كانت النسخة محلية أو مأخوذة من جهاز مرتبط بالسحابة. يجري فحصها وترقيتها على نسخة منفصلة مع ترك الملف الأصلي كما هو. الاستعادة تنقل بيانات العمل فقط وتحتفظ بحسابات الدخول الحالية وصلاحياتها. تُحفظ نسخة قبل استبدال البيانات.

لا يمكن ضمان قراءة صيغة مستقبلية غير معروفة، أو إصلاح ملف تالف بإخفاء رسالة الخطأ. في هذه الحالات يتوقف البرنامج قبل استبدال البيانات ويوضح المطلوب. كذلك الإصدار القديم المثبّت لا يكتسب إصلاح المستورد إلا بعد تحديثه إلى 0.4.2 أو أحدث.

أيقونة Windows تُضمّن في الملف التنفيذي ويُفحص تطابقها مع شعار الشركة أثناء النشر. لو ظل اختصار مثبت قديم يعرض الأيقونة السابقة بعد التحديث، أزل تثبيته من شريط المهام وثبّت الاختصار الجديد مجددًا.
