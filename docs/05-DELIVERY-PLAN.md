# خطة التنفيذ ومعايير القبول

## طريقة العمل

لا يبدأ بناء التطبيق في هذه المهمة: طلب المستخدم التصور والخطة ثم البدء لاحقًا. بعد أمر البدء تنفذ المراحل التالية تباعًا، مع نتيجة قابلة للفحص وتحديث HANDOFF.md في نهاية كل مرحلة. لا تُسجل مرحلة مكتملة بمجرد رسم واجهتها.

| المرحلة | التسليم | شرط الاكتمال |
|---|---|---|
| P0 التخطيط | هذه الوثائق وفحص المصدر وتأكيد الساعات والتشغيل | مكتملة كخطة؛ القرارات المتبقية مسجلة |
| P1 أساس التطبيق | مشروع Electron/React/TypeScript، مخطط SQLite أولي، بيانات مصطنعة، تعليمات التشغيل | تشغيل Windows وتغليف تجريبي ناجح وقراءة/كتابة محلية وعزل الواجهة مثبت |
| P2 محرك الحساب | القواعد المؤكدة والتقريب والتحقق وشرح كل بند | كل أمثلة الحساب وحدود الصندوق والأوضاع والتقريب ناجحة |
| P3 الموظفون والاستيراد | ملفات موظفين ومشاريع، المعاينة والتصنيف ومنع التكرار، تاريخ الأساسي | استيراد مختار دون بنود غير موظفين تلقائيًا، عدد نتائج مطابق، إعادة الاستيراد بلا تكرار |
| P4 مسير الشهر والسلف | إدخال جماعي وحفظ واستكمال، مراجعة واعتماد، تخصيص سلف، سجل وصرف | مسير كامل يعمل ويحفظ التاريخ ويمنع الخصم المتكرر ويستعيد مسودة بعد إعادة التشغيل |
| P5 الهوية والمخرجات | القسيمة والكشوف وPDF وExcel ومركز الطباعة | تطابق الأرقام بصريًا وحسابيًا، عربية واضحة، لا قص للشعار والأسماء والإجماليات |
| P6 تشغيل فعلي | مثبت، نسخ واستعادة، دليل مختصر، اختبار أداء وأخطاء | استعادة مجربة، ترقية مجربة، عينة فعلية يراجعها المستخدم مقابل حساب مستقل |

يمكن بناء نموذج بصري في P1 ببيانات مصطنعة، لكن أرقام العرض ليست دليلًا على اكتمال المحرك. بدء التعامل مع بيانات العمال الفعلية بعد نجاح البنية ومعاينة التصنيف في P3.

## اختبارات لازمة

### الحساب

أمثلة المستند 02 كاملة، الصندوق أسفل/عند/أعلى 5000، مبالغ كبيرة دون سقف صندوق، الغياب الكسري، فرق التقريب المبكر، صفر مقابل فارغ، التكليف مبلغ مقابل أيام، ساعتان تأخير عند أساسي 6000 تساويان 400، وكل زيادة في بند استحقاق ترفع الصافي بنفسها وكل خصم يخفضه بنفسه. منع جمع الأيام مع المبالغ.

### البيانات والتاريخ

كود موظف لا يتكرر، موظف بنفس الاسم لا يندمج تلقائيًا، إضافة وتعطيل واستعادة، تغيير الأساسي والمشروع لا يؤثر على شهر معتمد، اختيار السنة لا يخلط نفس الشهر في عام آخر، نسخة مصروفة لا تُعدل بلا مراجعة وتسوية، حفظ دفعة واحدة إما ينجح كاملًا أو لا يترك نصف نتيجة.

### الاستيراد

الأصل بلا تعديل، صفوف الإجماليات لا تصبح موظفين، الحالات 7 و34 و36 و88 و97 تظهر للمراجعة، لا استنتاج بيانات حساب من QNB، معاملة «دفعة التخرج» كنص، الفروق في المشاريع تُعرض، إعادة الملف/إعادة محاولة بعد انقطاع لا تكرر الإدخال، ملف غير صالح ينتج خطأ مفهومًا لا قاعدة نصف مستوردة.

### المخرجات

مجموع القسائم = كشف الشهر = Excel = PDF لنفس الإصدار والفلاتر. حالات اسم طويل ووظيفة طويلة وصافي كبير/صفر وبنود جميعها موجودة، A4 وA5 وقسيمتان في A4، أبيض وأسود، ألف صف Excel ومئة قسيمة PDF. فتح Excel للتحقق من الأرقام والتواريخ. تفتيش صفحات PDF بصريًا، لا الاكتفاء بوجود ملف. تجربة طابعة فعلية لتثبيت الهوامش والمقاس؛ تُسجل إن لم تكن متاحة.

### الحماية والاستعادة

الواجهة لا تشغل أوامر أو SQL، النصوص المشابهة للمعادلات تبقى نصًا، عدم فتح روابط خارجية من مدخلات الملفات، إلغاء اختيار ملف آمن، امتلاء القرص وفشل الطباعة لا يظهران كنجاح، استرجاع نسخة صالحة ورفض نسخة تالفة، إعادة التشغيل بعد إغلاق غير متوقع، ترقية المخطط مع نسخة رجوع.

## القرارات التي لا تؤخر البناء المستقل

تأكيد بند جزاءات أخرى وسياسة التقريب وأهلية الشهر الجزئي ومعالجة الصافي السالب يمكن استكمالها أثناء بناء الأساس، لكن يلزم حسم أي منها قبل اعتماد رواتب فعلية تتأثر به. قائمة الاستيراد تعرض القرارات الخاصة بكل صف عند الوصول لها. لا يعاد سؤال المستخدم عن الساعات أو الجهاز الواحد؛ تم تأكيدهما.

## تسليم كل مرحلة

سجل ما أُضيف، الملفات المهمة، طريقة التشغيل، الاختبارات المنفذة ونتائجها، ما لم يُختبر وسببه، الأخطاء الحالية، الخطوة التالية المحددة. أضف migration لكل تغيير بيانات، واستخدم بيانات مصطنعة في الاختبارات. احتفظ بملف قفل المكتبات وإرشادات إعداد الجهاز. لا ترفع النسخ المرجعية أو قاعدة البيانات الفعلية إلى Git.

## سيناريو عرض للإدارة

بحث عن موظف ثم تعديل تكليف 3 أيام ومشاهدة شرحه، تغيير ساعات التأخير وإظهار تطبيق القاعدة المطلوبة، مراجعة إجمالي مشروع، اعتماد شهر تجريبي، عرض قسيمة تحمل اللوجو وصافيًا واضحًا، ثم طباعة مجموعة وتصدير Excel بالأرقام نفسها. أخيرًا إظهار أن تعديل الأساسي للشهر التالي لا يغير القسيمة القديمة. العرض يستخدم بيانات مصطنعة حتى مراجعة البيانات الحقيقية.
