# النسخة المحلية 0.5.0

هذا الإصدار يعمل دون إنترنت: تسجيل الدخول والحسابات والموظفون والرواتب والاستيراد والتصدير والنسخ الاحتياطية كلها محلية. لا يشغّل Supabase أو مراقبة الاتصال أو التحديث التلقائي، ويرفض الطلبات الخارجية من نوافذ التطبيق. لا توجد مفاتيح اتصال سحابي ضمن ملفات التثبيت.

ثبّت `Kayan Payroll Setup 0.5.0.exe` بعد حفظ العمل وإغلاق النسخة القديمة. التثبيت وحده لا يحتاج إنترنت. النسخ السابقة تظل تتصل حتى يتم استبدالها بهذه النسخة على كل جهاز.

عند أول تشغيل تُنشأ قاعدة `%APPDATA%\kayan-payroll\payroll-data\offline.sqlite`. إذا كانت هناك نسخة سحابية سبق تنزيلها على الجهاز، تُنسخ بياناتها المحلية مع الحسابات المحلية القديمة إن وجدت. وإلا تستخدم قاعدة `payroll.sqlite` القديمة. لا يتم طلب بيانات من الإنترنت أثناء التحويل. أي بيانات لم تصل إلى هذا الجهاز أصلًا ليست ضمن هذه النسخة.

تظل الملفات الأصلية محفوظة، وتُنشأ نسخة قبل الفصل. يسجل `offline-migration.json` المصدر وأي عمليات سابقة لم تكن مطبقة محليًا. هذه العمليات لا تُنفّذ تخمينًا؛ تفاصيلها تظل في قاعدة السحابة القديمة للمراجعة. على جهاز لم تكن له حسابات محلية، تظهر شاشة إعداد حساب مدير محلي جديد؛ كلمة مرور الحساب السحابي لا يمكن استخراجها من جلسة الدخول.

منذ أول تشغيل تستخدم النسخة المحلية قاعدتها المستقلة ولا تعيد نسخ القاعدة القديمة فوق التعديلات الجديدة. الحسابات وكلمات المرور والتعديلات مستقلة لكل جهاز. لم تعد الأجهزة تتبادل البيانات أو تتلقى تحديثات تلقائيًا؛ نقل البيانات يتم بملف Excel أو نسخة احتياطية، وتحديث البرنامج يتم بمثبت جديد يدويًا.

المشروع السحابي القديم لم يُحذف، حفاظًا على بياناته. تطبيق 0.5.0 لا يتصل به.

البناء: `npm run release` ينفذ الاختبارات ويبني المثبت محليًا فقط. لا تستخدم سكربت النشر السحابي القديم لهذا الإصدار.
