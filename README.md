# كيان — نظام الرواتب المحلي

الإصدار الحالي: **0.5.3**. تطبيق Windows عربي يعمل دون إنترنت لمساحة عمل محلية.

يشمل ملفات الموظفين، المتابعة اليومية، الرواتب الشهرية، المستحق حتى تاريخ محدد، معادلات قابلة للتعديل، وتصدير PDF وExcel ونسخًا احتياطية.

## التشغيل والتطوير

- `npm run build` لبناء التطبيق.
- `npm start` لتشغيله.
- `npm test` لاختبارات الحسابات والحفظ والترقية.
- `npm run test:e2e` لاختبار دورة الرواتب والتصدير والاستعادة.
- `npm run test:daily:e2e` لاختبار المتابعة اليومية وملفات الموظفين والمعادلات.
- `npm run test:admin:e2e` لاختبار الحسابات والحذف وإعادة الضبط.
- `npm run test:packaged` لاختبار النسخة المجمعة.
- `npm run dist` لإنشاء مثبت Windows في `release`.

راجع [الحسابات وإعادة الضبط](docs/07-ADMIN-RESET.md)، ثم [دليل الاستخدام وقواعد الإصدار](docs/06-DAILY-V2.md) و[ملف تسليم المشروع](HANDOFF.md) قبل أي تعديل. مستندات 01–05 هي التخطيط الأصلي؛ هذا الإصدار وملف التسليم يوضحان الحالة الحالية.

بيانات التشغيل تحفظ خارج مجلد البرنامج داخل مجلد المستخدم. الاختبارات تستخدم بيانات منفصلة داخل `data` ولا تعدّل ملفات الموظفين الأصلية. المصادر الخاصة في `reference/private` لا تُنشر.

لنقل بيانات العمل إلى حساب Windows أو جهاز آخر: أنشئ نسخة احتياطية من الإعدادات في الجهاز الحالي، ثم استخدم «استعادة نسخة سابقة» في الجهاز الآخر. نقل البرنامج وحده لا ينقل قاعدة البيانات.
